# 苏牌甄选

江苏地区车牌号码吉凶甄选工具。

纯前端单文件应用，所有计算与 OCR 识别均在浏览器本地完成，不上传任何数据。

## 功能

- **机选号码** — 随机生成符合江苏编码规则的蓝牌/绿牌号码，支持批量对比与智能优选
- **图片选号** — 上传选号界面截图，Tesseract.js 自动识别候选号码并排序
- **手动测号** — 输入任意号码即时测算

## 评分维度

| 维度 | 说明 |
|------|------|
| 五格数理 | 天格、人格、地格、外格、总格 |
| 81 数理 | 数字对 80 取模查吉凶表 |
| 谐音寓意 | 数字与字母的谐音评分 |
| 特殊组合 | 连号、顺子、豹子等加分 |

## 评级

SR 天选 → SSS 极品 → SS 臻选 → S 优选 → A 上等 → B 吉利 → C 中等 → D 平稳 → E 偏弱 → F 不佳
